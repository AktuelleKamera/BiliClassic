# BiliClassic for Windows Phone

一个面向Windows Phone设备的第三方哔哩哔哩客户端，让被遗忘在抽屉里的Windows Phone设备重新获得观看哔哩哔哩视频的能力。

## 技术路线

- 基于 Sliverlight 4 开发
- 使用 Visual Studio 2010/Visual Studio 2015 构建

## 本项目是如何出现的？

开发者发现WP7还是没有完美的客户端，不想看鱼与熊掌的故事，于是就尝试顺手做了一个喵~

当然WP8也能用的，所以……还记得哔哩Metro吗？
