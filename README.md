## 当前版本

**0.1.0 (MiniOne)**

## 技术路线

- 基于 Mzfc 1.0.0.1 开发
- 使用 Visual Studio 2008 构建

## 项目介绍

本项目在魅族M8上实现了30FPS的240P H.264 Baseline视频播放，同时带30FPS弹幕

可能是CE内核上体验最好的B站客户端之一（去掉微软自家的两个改版的话）

## 本项目是如何出现的？

开发者发现魅族M8的外放非常不错，刚好自己做了WM/CE版，于是照着改成了C，就这样出了一个效果还不错的客户端（
